# 代码审查技能

本技能用于执行代码审查任务，支持：
- 代码风格检查
- 潜在 Bug 检测
- 性能问题识别
- 安全漏洞扫描
- 最佳实践建议

## 审查范围

### 1. 代码质量
- 代码可读性
- 命名规范
- 注释完整性

### 2. 潜在问题
- 空指针引用
- 资源泄露
- 并发问题

### 3. 性能优化
- 循环优化
- 内存使用
- 算法复杂度

### 4. 安全审查
- SQL 注入
- XSS 漏洞
- 敏感信息泄露

## 输出格式

审查结果将按以下格式呈现：
1. 问题列表
2. 严重程度（高/中/低）
3. 修复建议
4. 代码示例
