# 数据分析技能

本技能用于执行数据分析任务，支持：
- 数据加载和清洗
- 统计分析和计算
- 数据可视化
- 分析报告生成

## 使用方法

### 1. 环境准备
确保 Python 环境已安装，所需库：
- pandas
- numpy
- matplotlib
- seaborn

### 2. 数据分析流程

```
输入数据 -> 数据清洗 -> 统计分析 -> 可视化 -> 报告生成
```

### 3. 注意事项
- 确保数据文件格式正确
- 注意数据隐私保护
- 生成的可视化图像保存在 output/ 目录
