<h1>第七章：记忆系统</h1> <p>记忆系统是 AgentScope Java 框架的核心组件之一，它负责管理和持久化 Agent 与用户之间的对话历史。本章将详细介绍记忆的类型与实现、消息累加器机制、对话历史管理，以及记忆压缩与摘要功能。</p> <h2>7.1 记忆类型与实现</h2> <p>AgentScope Java 提供了两种主要的记忆类型：会话级记忆（Memory）和长期记忆（LongTermMemory）。</p> <h3>7.1.1 会话级记忆（Memory）</h3> <p>会话级记忆用于存储单个会话内的对话历史，是 Agent 最基础的记忆组件。</p> <p>**Memory 接口定义：**</p> <pre><code class="language-java">public interface Memory extends StateModule { /** * 添加消息到记忆 */ void addMessage(Msg message); <p>/** * 获取所有存储的消息 */ List&lt;Msg&gt; getMessages();</p> <p>/** * 删除指定索引的消息 */ void deleteMessage(int index);</p> <p>/** * 清空所有消息 */ void clear(); } </code></pre></p> <p>**InMemoryMemory 实现：**</p> <code>InMemoryMemory</code> 是 Memory 接口的内存实现，采用线程安全的 <code>CopyOnWriteArrayList</code> 存储消息，并支持通过 Session 进行状态持久化。 <pre><code class="language-java">public class InMemoryMemory implements Memory { private final List&lt;Msg&gt; messages = new CopyOnWriteArrayList&lt;&gt;(); private static final String KEY_PREFIX = &quot;memory&quot;; <p>@Override public void addMessage(Msg message) { messages.add(message); }</p> <p>@Override public List&lt;Msg&gt; getMessages() { return messages.stream() .filter(Objects::nonNull) .collect(Collectors.toList()); }</p> <p>@Override public void saveTo(Session session, SessionKey sessionKey) { session.save(sessionKey, KEY_PREFIX + &quot;_messages&quot;, new ArrayList&lt;&gt;(messages)); }</p> <p>@Override public void loadFrom(Session session, SessionKey sessionKey) { List&lt;Msg&gt; loaded = session.getList(sessionKey, KEY_PREFIX + &quot;_messages&quot;, Msg.class); messages.clear(); messages.addAll(loaded); } } </code></pre></p> <h3>7.1.2 长期记忆（LongTermMemory）</h3> <p>长期记忆允许 Agent 跨会话记忆用户偏好、重要事实等信息，适用于多会话场景下的个性化服务。</p> <p>**LongTermMemory 接口：**</p> <pre><code class="language-java">public interface LongTermMemory { /** * 记录消息到长期记忆 */ Mono&lt;Void&gt; record(List&lt;Msg&gt; msgs); <p>/** * 根据输入检索相关记忆 */ Mono&lt;String&gt; retrieve(Msg msg); } </code></pre></p> <h3>7.1.3 记忆模式配置</h3> <code>LongTermMemoryMode</code> 枚举控制长期记忆的集成方式： <table border="1" cellpadding="8" cellspacing="0"><thead><tr><th>模式</th><th>说明</th></tr></thead><tbody><tr><td><code>AGENT_CONTROL</code></td><td>Agent 通过工具调用主动管理记忆</td></tr><tr><td><code>STATIC_CONTROL</code></td><td>框架自动管理记忆，无需 Agent 介入</td></tr><tr><td><code>BOTH</code></td><td>结合两种模式（推荐默认值）</td></tr></tbody></table> <p>**配置示例：**</p> <pre><code class="language-java">ReActAgent agent = ReActAgent.builder() .name(&quot;Assistant&quot;) .model(model) .memory(new InMemoryMemory()) // 会话级记忆 .longTermMemory(longTermMemory) // 长期记忆 .longTermMemoryMode(LongTermMemoryMode.BOTH) // 推荐模式 .build(); </code></pre> <h2>7.2 消息累加器（Accumulator）</h2> <p>消息累加器用于处理流式响应中的内容块，将分散的块聚合为完整的消息。</p> <h3>7.2.1 ContentAccumulator 接口</h3> <pre><code class="language-java">public interface ContentAccumulator&lt;T extends ContentBlock&gt;
