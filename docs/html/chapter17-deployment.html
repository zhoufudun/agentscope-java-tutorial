└────────────────────────────────────────────────────┘ │ │ │ │ │ ▼ │ │ 4. 关闭数据库连接池 │ │ │ │ │ ▼ │ │ 5. 关闭线程池 │ │ │ │ │ ▼ │ │ 6. 进程退出 │ │ │
