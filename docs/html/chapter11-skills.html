<h1>第十一章：技能系统</h1> <p>> 本章节配套完整可运行的 Spring Boot 项目，演示如何使用 AgentScope Java 的技能（Skill）系统实现动态技能加载与持久化存储。</p> <h2>11.1 技能（Skill）的定义</h2> <h3>11.1.1 什么是 Skill</h3> <p>在 AgentScope Java 中，**技能（Skill）** 是扩展智能体能力的模块化数据包。每个 Skill 包含指令、元数据（metadata）和可选资源（如脚本、参考文档、示例等），智能体在执行相关任务时会自动加载并使用这些资源。</p> <p>与直接给智能体喂大量上下文不同，Skill 采用**渐进式披露（Progressive Disclosure）**机制： <ul><li>**阶段一**：智能体启动时，系统中只加载技能的元数据（name、description），约 100 tokens/Skill</li> <li>**阶段二**：AI 判断任务需要某个 Skill 时，调用 <code>load_skill_through_path</code> 工具加载完整指令（通常 <5k tokens）</li> <li>**阶段三**：智能体按需访问 Skill 附带的资源文件（如参考文档、脚本等）</li> </ul> 这种设计显著减少了初始上下文大小，同时保证智能体在需要时能获取完整技能内容。</p> <h3>11.1.2 Skill 的结构</h3> <p>一个标准 Skill 的目录结构如下：</p> <pre><code class="language-text">skill-name/ ├── SKILL.md # 必需：入口文件，包含 YAML frontmatter 和技能指令 ├── references/ # 可选：详细参考文档 │ ├── api-doc.md │ └── best-practices.md ├── examples/ # 可选：工作示例 │ └── example1.java └── scripts/ # 可选：可执行脚本 └── process.py </code></pre> <p>**SKILL.md 格式**：</p> <pre><code class="language-yaml">--- name: skill-name # 必需：技能名称（小写字母、数字、下划线） description: This skill should be used when... # 必需：触发描述，说明何时使用 homepage: https://example.com/docs # 可选：额外元数据 metadata: clawdbot: requires: env: <ul><li>API_KEY</li> </ul>--- <h1>技能名称</h1> <h2>功能概述</h2> [详细说明该技能的功能] <h2>使用方法</h2> [使用步骤和最佳实践] </code></pre> <h3>11.1.3 AgentSkill 类</h3> <p>在代码中，技能由 <code>io.agentscope.core.skill.AgentSkill</code> 类表示，核心字段如下：</p> <table border="1" cellpadding="8" cellspacing="0"><thead><tr><th>字段</th><th>说明</th></tr></thead><tbody><tr><td><code>name</code></td><td>技能名称，从 metadata 中提取</td></tr><tr><td><code>description</code></td><td>技能描述，AI 据此判断何时使用该技能</td></tr><tr><td><code>skillContent</code></td><td>技能的完整内容（SKILL.md 正文）</td></tr><tr><td><code>resources</code></td><td>资源文件 Map（path -> content）</td></tr><tr><td><code>metadata</code></td><td>完整元数据 Map</td></tr></tbody></table> <p>**创建 Skill 的三种方式**：</p> <pre><code class="language-java">// 方式一：使用 Builder（推荐） AgentSkill skill = AgentSkill.builder() .name(&quot;data_analysis&quot;) .description(&quot;Use this skill when analyzing data, calculating statistics, or generating reports&quot;) .skillContent(&quot;# Data Analysis\n...&quot;) .addResource(&quot;references/api-doc.md&quot;, &quot;# API Reference\n...&quot;) .addResource(&quot;scripts/process.py&quot;, &quot;def process(data): ...\n&quot;) .source(&quot;custom&quot;) .build(); <p>// 方式二：从 Markdown 创建 String skillMd = &quot;&quot;&quot; --- name: data_analysis description: Use this skill when analyzing data --- <h1>Data Analysis</h1> Content... &quot;&quot;&quot;; Map&lt;String, String&gt; resources = Map.of(&quot;references/formulas.md&quot;, &quot;# Formulas\n...&quot;); AgentSkill skill = SkillUtil.createFrom(skillMd, resources);</p> <p>// 方式三：直接构造 AgentSkill skill = new AgentSkill( &quot;data_analysis&quot;, &quot;Use when analyzing data...&quot;, &quot;# Data Analysis\n...&quot;, resources ); </code></pre></p> <h3>11.1.4 内置 Skill 工具</h3> <p>AgentScope 为 Skill 系统内置了 <code>load_skill_through_path</code> 工具：</p> <pre><code class="language-java">// 工具签名 load_skill_through_path(skillId: enum, resourcePath?: string) </code></pre> <ul><li>**<code>skillId</code>**：枚举字段，只能从已注册的 Skill 中选择，保证准确性</li> <li>**<code>resourcePath</code>**：相对于 Skill 根目录的资源路径（如 <code>references/api-doc.md</code>）</li> <li>路径错误时返回所有可用资源路径列表，帮助 LLM 自我纠正</li> </ul> <h2>11.2 技能注册与调用</h2> <h3>11.2.1 SkillBox：技能容器</h3> <code>SkillBox</code> 是技能系统的核心组件，负责： <p>1. 持有 <code>Toolkit</code> 并注册所有 Skill 2. 生成技能系统提示词（注入到 Agent 的 system prompt 中） 3. 管理 Skill 与 Tool 的绑定关系</p> <pre><code class="language-java">// 基础用法 Toolkit toolkit = new Toolkit(); SkillBox skillBox = new SkillBox(toolkit); <p>// 注册技能 skillBox.registerSkill(dataSkill); skillBox.registerSkill(sqlSkill);</p> <p>// 或使用 registration() 进行链式注册（支持 Skill 与 Tool 绑定） skillBox.registration() .skill(dataSkill) .tool(loadDataTool) // 将 Tool 绑定到该 Skill，仅在 Skill 激活时生效 .apply(); </code></pre></p> <h3>11.2.2 将 Skill 集成到 Agent</h3> <pre><code class="language-java">// 方式一：使用 SkillBox（推荐） SkillBox skillBox = new SkillBox(new Toolkit()); skillBox.registerSkill(mySkill); <p>ReActAgent agent = ReActAgent.builder() .name(&quot;MyAssistant&quot;) .model(model) .skillBox(skillBox) .build();</p> <p>// 方式二：同时使用 Toolkit 和 SkillBox Toolkit toolkit = new Toolkit(); SkillBox skillBox = new SkillBox(toolkit); skillBox.registerSkill(mySkill);</p> <p>ReActAgent agent = ReActAgent.builder() .name(&quot;MyAssistant&quot;) .model(model) .toolkit(toolkit) .skillBox(skillBox) // 自动注册 skill 工具 .memory(new InMemoryMemory()) .build(); </code></pre></p> <h3>11.2.3 渐进式披露的 Tool 生命周期</h3> <p>将 Tool 与 Skill 绑定后，Tool 的生命周期与 Skill 保持一致： <ul><li>Skill 激活后，绑定的 Tool 在整个会话期间保持可用</li> <li>避免了旧机制中每轮对话后 Tool 失活导致的调用失败问题</li> </ul> <pre><code class="language-java">SkillBox skillBox = new SkillBox(toolkit);</p> <p>AgentTool dataLoadTool = new AgentTool(...); AgentTool reportGenTool = new AgentTool(...);</p> <p>// 为不同 Skill 绑定不同的 Tool skillBox.registration() .skill(dataSkill) .tool(dataLoadTool) .apply();</p> <p>skillBox.registration() .skill(reportSkill) .tool(reportGenTool) .apply(); </code></pre></p> <h3>11.2.4 自定义技能提示词</h3> <p>SkillBox 默认会为每个注册的 Skill 生成 XML <code><skill></code> 条目注入到系统提示词。可以通过 <code>instruction</code> 参数自定义提示词头部：</p> <pre><code class="language-java">// 自定义 instruction 头部 String customInstruction = &quot;&quot;&quot; ## 可用技能 当任务匹配某个技能时，使用 load_skill_through_path 加载它。 &quot;&quot;&quot;; <p>SkillBox skillBox = new SkillBox(toolkit, customInstruction);</p> <p>// 可选：仅向 prompt 暴露核心 metadata skillBox.setExposeAllSkillMetadata(false); </code></pre></p> <h2>11.3 技能仓库（MySQL / Git）</h2> <p>AgentScope 提供了多种 Skill 持久化存储方案，支持从不同来源加载技能。</p> <h3>11.3.1 仓库接口</h3> <p>所有仓库实现 <code>io.agentscope.core.skill.repository.AgentSkillRepository</code> 接口：</p> <pre><code class="language-java">public interface AgentSkillRepository extends AutoCloseable { AgentSkill getSkill(String name); List&lt;String&gt; getAllSkillNames(); List&lt;AgentSkill&gt; getAllSkills(); boolean save(List&lt;AgentSkill&gt; skills, boolean force); boolean delete(String skillName); boolean skillExists(String skillName); AgentSkillRepositoryInfo getRepositoryInfo(); String getSource(); } </code></pre> <h3>11.3.2 MySQL 存储</h3> <p>使用 <code>MysqlSkillRepository</code> 将技能存储到 MySQL 数据库。数据库表结构如下：</p> <pre><code class="language-sql">-- 技能主表 CREATE TABLE agentscope_skills ( id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY, name VARCHAR(255) NOT NULL UNIQUE, description TEXT NOT NULL, skill_content LONGTEXT NOT NULL, source VARCHAR(255) NOT NULL, metadata_json LONGTEXT NULL, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP ) DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; <p>-- 技能资源表 CREATE TABLE agentscope_skill_resources ( id BIGINT NOT NULL, resource_path VARCHAR(500) NOT NULL, resource_content LONGTEXT NOT NULL, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, PRIMARY KEY (id, resource_path), FOREIGN KEY (id) REFERENCES agentscope_skills(id) ON DELETE CASCADE ) DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; </code></pre></p> <p>**使用方式**：</p> <pre><code class="language-java">// 简单构造函数（使用默认数据库/表名） DataSource dataSource = createDataSource(); MysqlSkillRepository repo = new MysqlSkillRepository(dataSource, true, true); <p>// 使用 Builder 进行自定义配置 MysqlSkillRepository repo = MysqlSkillRepository.builder(dataSource) .databaseName(&quot;my_database&quot;) .skillsTableName(&quot;my_skills&quot;) .resourcesTableName(&quot;my_resources&quot;) .createIfNotExist(true) .writeable(true) .build();</p> <p>// 保存技能 repo.save(List.of(skill), false);</p> <p>// 加载技能 AgentSkill loaded = repo.getSkill(&quot;data_analysis&quot;);</p> <p>// 列出所有技能 List&lt;AgentSkill&gt; allSkills = repo.getAllSkills();</p> <p>// 删除技能 repo.delete(&quot;old_skill&quot;); </code></pre></p> <h3>11.3.3 Git 仓库（只读）</h3> <p>使用 <code>GitSkillRepository</code> 从 Git 仓库加载技能（只读），支持 HTTPS 和 SSH：</p> <pre><code class="language-java">// 自动同步模式（默认每次读取检查远端变化） AgentSkillRepository repo = new GitSkillRepository( &quot;https://github.com/your-org/your-skills-repo.git&quot;); AgentSkill skill = repo.getSkill(&quot;data-analysis&quot;); List&lt;AgentSkill&gt; allSkills = repo.getAllSkills(); <p>// 手动同步模式 GitSkillRepository manualRepo = new GitSkillRepository( &quot;https://github.com/your-org/your-skills-repo.git&quot;, false); manualRepo.sync(); // 手动刷新 </code></pre></p> <h3>11.3.4 Classpath 仓库（只读）</h3> <p>从 classpath 资源中加载预打包的 Skills，适用于 JAR 或 Spring Boot Fat JAR：</p> <pre><code class="language-java">try (ClasspathSkillRepository repository = new ClasspathSkillRepository(&quot;skills&quot;)) { AgentSkill skill = repository.getSkill(&quot;data-analysis&quot;); List&lt;AgentSkill&gt; allSkills = repository.getAllSkills(); } </code></pre> <p>资源目录结构：<code>src/main/resources/skills/</code> 下放置多个 Skill 子目录，每个子目录包含 <code>SKILL.md</code>。</p> <h3>11.3.5 文件系统仓库</h3> <p>从本地文件系统加载技能：</p> <pre><code class="language-java">AgentSkillRepository repo = new FileSystemSkillRepository(Path.of(&quot;./skills&quot;)); repo.save(List.of(skill), false); AgentSkill loaded = repo.getSkill(&quot;data_analysis&quot;); </code></pre> <h3>11.3.6 Nacos 仓库（只读）</h3> <p>从 Nacos 配置中心实时拉取或订阅 Skill，适合需要与 Nacos 保持同步的在线场景：</p> <pre><code class="language-java">// 需引入 agentscope-extensions-nacos-skill 依赖 try (NacosSkillRepository repository = new NacosSkillRepository(aiService, &quot;namespace&quot;)) { AgentSkill skill = repository.getSkill(&quot;data-analysis&quot;); boolean exists = repository.skillExists(&quot;data-analysis&quot;); } </code></pre> <h2>11.4 【案例】动态技能加载</h2> <p>本案例使用 Java 21 + Spring Boot 3 + H2 嵌入式数据库，完整演示： <ul><li>技能的定义与注册</li> <li>MySQL 风格存储（使用 H2 模拟 MySQL 表结构）</li> <li>动态技能加载与执行</li> </ul> <h3>11.4.1
