<code>@ConfigurationProperties</code> 机制实现，遵循"约定优于配置"原则。</p> <h3>16.2.1 核心自动配置类</h3> <code>AgentscopeAutoConfiguration</code> 是核心配置类，它在 <code>META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports</code> 中声明，Spring Boot 启动时自动加载。 <p>关键设计：</p> <p>**1. 原型作用域的组件 Bean**</p> <p>由于 ReActAgent、Memory、Toolkit 都是**有状态且非线程安全**的，它们被注册为 <code>prototype</code> 作用域 Bean，确保每个请求获得独立实例：</p> <pre><code class="language-java">/** * Memory Bean - 原型作用域，每次注入创建新实例 * 有状态，非线程安全，每个会话独立使用 */ @Bean @ConditionalOnProperty(prefix = &quot;agentscope.agent&quot;, name = &quot;enabled&quot;, havingValue = &quot;true&quot;) @ConditionalOnMissingBean @Scope(ConfigurableBeanFactory.SCOPE_PROTOTYPE) public Memory agentscopeMemory() { return new InMemoryMemory(); } <p>/** * ReActAgent Bean - 原型作用域 * 在 Controller/Service 中通过 ObjectProvider&lt;ReActAgent&gt; 按需获取 */ @Bean @ConditionalOnMissingBean @ConditionalOnProperty(prefix = &quot;agentscope.agent&quot;, name = &quot;enabled&quot;, havingValue = &quot;true&quot;) @Scope(ConfigurableBeanFactory.SCOPE_PROTOTYPE) public ReActAgent agentscopeReActAgent( Model model, Memory memory, Toolkit toolkit, AgentscopeProperties properties) { AgentProperties config = properties.getAgent(); return ReActAgent.builder() .name(config.getName()) .sysPrompt(config.getSysPrompt()) .model(model) .memory(memory) .toolkit(toolkit) .maxIters(config.getMaxIters()) .build(); } </code></pre></p> <p>**2. 多模型提供商支持**</p> <p>通过 <code>ModelProviderType</code> 枚举根据配置自动选择模型客户端：</p> <pre><code class="language-java">public enum ModelProviderType { DASHSCOPE, // 阿里云百炼 OPENAI, // OpenAI 及兼容 API GEMINI, // Google Gemini ANTHROPIC; // Anthropic Claude <p>public static ModelProviderType fromProperties(AgentscopeProperties properties) { ModelProperties modelConfig = properties.getModel(); String provider = modelConfig.getProvider(); if (provider != null) { try { return ModelProviderType.valueOf(provider.toUpperCase()); } catch (IllegalArgumentException e) { // 默认使用 DashScope } } return DASHSCOPE; } } </code></pre></p> <h3>16.2.2 配置属性绑定</h3> <p>所有配置通过 <code>application.yml</code> 中的 <code>agentscope.*</code> 前缀统一管理：</p> <pre><code class="language-yaml">agentscope: # 模型提供商配置 model: provider: dashscope # dashscope | openai | gemini | anthropic <p># 阿里云百炼配置（默认） dashscope: enabled: true api-key: ${DASHSCOPE_API_KEY} model-name: qwen-plus stream: true enable-thinking: true</p> <p># OpenAI
