<h1>第十五章：Harness 安全执行环境</h1> <p>Harness 是 AgentScope Java 框架为 Agent 提供的一套安全、隔离、可持久化的执行环境。相比基础的 ReActAgent，HarnessAgent 在以下方面提供了增强： <ul><li>**工作区管理**：基于磁盘的上下文加载（AGENTS.md、MEMORY.md 等）</li> <li>**沙箱隔离**：支持 Docker、Kubernetes 等容器化执行环境，代码在隔离环境中运行</li> <li>**文件系统抽象**：统一的文件系统 API，支持本地、沙箱、远程等多种后端</li> <li>**内存刷新与压缩**：对话过长时自动触发摘要/压缩，防止上下文溢出</li> <li>**会话持久化**：支持跨会话恢复 Agent 状态和沙箱工作区</li> </ul> 本章将深入剖析 Harness 的架构设计，并通过完整案例演示其核心功能。</p> <h2>15.1 Harness 架构与原理</h2> <h3>15.1.1 整体架构图</h3> <pre><code class="language-">┌─────────────────────────────────────────────────────────────┐ │ HarnessAgent SandboxExecutionGuard * 获取执行租约（SandboxLease），确保并发安全 */ public SandboxAcquireResult acquire(SandboxContext sandboxContext, RuntimeContext runtimeContext) { // Priority 1: 外部沙箱（跳过 guard） if (sandboxContext.getExternalSandbox() != null) { return SandboxAcquireResult.userManaged(externalSandbox); } <p>// Priority 2: 外部状态（跳过 guard） if (sandboxContext.getExternalSandboxState() != null) { Optional&lt;SandboxIsolationKey&gt; scopeKey = SandboxIsolationKey.resolve(sandboxContext.getIsolationScope(), runtimeContext, agentId);</p> <p>SandboxLease lease = SandboxLease.noop(); if (scopeKey.isPresent()) { lease = executionGuard.tryEnter(scopeKey.get()); // 获取执行租约 }</p> <p>// 尝试从持久化存储恢复 if (scopeKey.isPresent()) { Optional&lt;String&gt; stateJson = stateStore.load(scopeKey.get()); if (stateJson.isPresent()) { SandboxState state = client.deserializeState(stateJson.get()); Sandbox sandbox = client.resume(state); return SandboxAcquireResult.selfManaged(sandbox, lease); } }</p> <p>// Priority 4: 创建新沙箱 Sandbox sandbox = client.create(spec, snapshotSpec, clientOptions); return SandboxAcquireResult.selfManaged(sandbox, lease); } </code></pre></p> <h3>15.2.3 Docker 沙箱配置</h3> <code>DockerFilesystemSpec</code> 提供了简洁的 Docker 沙箱配置接口： <pre><code class="language-java">// 创建 Docker 沙箱文件系统规范 DockerFilesystemSpec fsSpec = new
