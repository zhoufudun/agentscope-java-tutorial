<h1>AgentScope Java 教程示例工程</h1> <p>> 每个章节对应一个独立可运行的 Spring Boot 项目</p> <h2>技术栈标准</h2> <ul><li>**Java**: 21</li> <li>**Spring Boot**: 3.x</li> <li>**依赖库**: Lombok, Apache Commons Lang3, Jackson</li> <li>**构建工具**: Maven</li> <li>**数据库**: MySQL 8 (Docker), H2 (开发模式)</li> <li>**缓存**: Redis (Docker)</li> <li>**向量数据库**: Qdrant (Docker, RAG 专用)</li> <li>**消息队列**: RocketMQ (Docker, A2A 章节可选)</li> </ul> <h2>目录结构</h2> <pre><code class="language-">tutorial/ ├── docker-compose.yml # Grafana 监控 curl http://localhost:9090/prometheus # Prometheus </code></pre> <p>**包含内容：** <ul><li>多阶段构建 Dockerfile (JRE 优化)</li> <li>docker-compose.yml (MySQL + Redis + Prometheus + Grafana + OTel Collector + Jaeger)</li> <li>Kubernetes 完整配置 (Deployment, Service, ConfigMap, Secret, HPA, PDB, Ingress, NetworkPolicy)</li> <li>Helm Chart 完整模板</li> <li>生产级配置 (优雅关闭、健康检查、监控指标)</li> </ul> ---</p> <h2>Docker 服务规划</h2> <table border="1" cellpadding="8" cellspacing="0"><thead><tr><th>服务</th><th>端口</th><th>用途</th><th>使用章节</th></tr></thead><tbody><tr><td>MySQL</td><td>3306</td><td>关系型数据库</td><td>大部分章节</td></tr><tr><td>Redis</td><td>6379</td><td>缓存/Session</td><td>7, 11, 16</td></tr><tr><td>Qdrant</td><td>6333</td><td>向量数据库</td><td>10</td></tr><tr><td>Nacos</td><td>8848</td><td>配置中心</td><td>9, 16</td></tr><tr><td>RocketMQ</td><td>9876/10911</td><td>消息队列</td><td>9</td></tr></tbody></table> <h2>运行方式</h2> <p>每个章节示例工程均支持：</p> <pre><code class="language-bash"># 开发模式 (使用 H2) ./mvnw spring-boot:run <h1>生产模式 (使用 MySQL)</h1> docker-compose up -d #
