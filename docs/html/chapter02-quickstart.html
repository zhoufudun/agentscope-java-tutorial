├─────────────────────────────────────────────────────────┤ │ │ │ ┌──────────┐ 1. 思考 (Reasoning) │ │ │ 开始 │──────────────────────────┐ │ │ └──────────┘ ▼ │ │ ┌──────────────┐ │ │ │ 思考当前状态 │ │ │ │ 决定下一步 │ │ │ └──────────────┘ │ │ │ │ │ 2. 行动 (Acting) │ │ ▼ │ │ ┌──────────────┐ │ │ │ 调用工具 │ │ │ │ 或生成回复 │ │ │ └──────────────┘ │ │ │ │ │ 3. 观察 (Observation) │ │ ▼ │ │ ┌──────────────┐ │ │ │ 获取工具结果 │ │ │ │ 或用户反馈 │ │ │ └──────────────┘ │ │ │ │ │ ┌───────┴───────┐ │ │ │ 达到终止条件? │ │ │ └───────────────┘ │ │ 是 │ 否 │ │ ▼ │ │ 回到 步骤1 │ │ │ │ 终止条件： │ │ - 生成了最终回复 │ │ - 达到最大迭代次数 │ │ - 用户中断 │ │ │ └─────────────────────────────────────────────────────────┘ </code></pre> <h3>核心方法</h3> <table border="1" cellpadding="8"
